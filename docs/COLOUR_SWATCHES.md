## Accent Opacity Scale

| Opacity | Approx Light Result | Usage |
|---------|---------------------|-------|
| `accent/5` | Very faint blue tint | Subtle hover |
| `accent/8` | Faint | Active nav item bg |
| `accent/10` | Light (= `--accent-subtle`) | Active button, selected state |
| `accent/15` | Visible | Updated badge |
| `accent/20` | Clear | Accent border |
| `accent/30` | Medium | Active element border |
| `accent/40` | Strong | Prominent border |
| `accent` (100%) | Full `#2563EB` | CTA, links, filter pills |

## Status Colour Variants

Each status colour has a full and subtle variant:

| Status | Full | Subtle (10–14% opacity bg) | Usage |
|--------|------|---------------------------|-------|
| Success | `#5A9A6B` / `#6AAA7B` | `rgba(90,154,107,0.10/0.14)` | Connected, saved, positive |
| Warning | `#C49432` / `#D4A442` | `rgba(196,148,50,0.10/0.14)` | Pending, caution, undeclared |
| Danger | `#C45454` / `#D46464` | `rgba(196,84,84,0.10/0.14)` | Error, broken, destructive |
